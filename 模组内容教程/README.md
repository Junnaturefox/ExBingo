# 模组内容教程

这份教程写给**想把自己装的模组内容加进 Bingo 卡片**的玩家和服主。

## 先说结论：现在只有原版棋盘

ExBingo 目前只自带 4 个原版棋盘：

| 棋盘 | 里面是什么 |
|---|---|
| 物品（`items`） | 通用物品收集 |
| 进度（`advancements`） | 原版成就类目标 |
| 精简（`simplified`） | 数量更少、更容易的目标 |
| 挑战（`challenge`） | 成组收集之类的挑战目标 |

以前随模组附带的其他模组棋盘（灾变、永恒星光、农夫乐事、冰火传说、暮色森林等）已经全部移除。

所以：

- 装了其他模组后，它们的物品和进度**默认不会**出现在卡片上。
- 想加回来，就是下面几份教程要解决的问题。

## 三种做法，按需要选

| 做法 | 适合什么情况 | 能做到多细 |
|---|---|---|
| **按模组整体引入** `/bingo filter +from=<模组id>` | 想把某个模组里已经分好类的内容直接拿进来用 | 比较粗，通常等于「这个模组的内容」 |
| **自己写棋盘文件** | 想精确决定每一格的目标和难度 | 最细，逐条可控 |
| **自动分级** `/bingo autotier generate` | 模组内容太多，懒得一条条分类 | 由模组按「多难拿到」自动估档 |

这三种也可以搭配：先自动分级得到一份难度表，再抄一份出来当自己的棋盘慢慢微调。

## 会影响结果的两个开关

在 `config/exbingo/config.json` 里，这两个设置默认都是开启的：

- **未分类的模组内容不进卡片**：用 `+from=<模组id>` 时建议同时加 `-uncategorized`，这样就只留下该模组已经分好类的内容；反过来，如果确实想把这个模组的所有东西都放进去，就去掉它。
- **不可破坏的方块不进卡片**：基岩、屏障、命令方块这类方块默认不会成为目标。

改完配置记得执行 `/reload` 或重启服务器。棋盘列表有缓存，重载之后才能看到新增或关闭的棋盘。
